# Project Statement

## Problem Statement

Managing student records manually can be time-consuming. It can also be
difficult to find a particular student, update marks, or calculate
performance.

This project is made to solve these problems using a simple Python
command-line program. It allows the user to manage student records and
calculate their academic performance.

## Scope of the Project

This project is mainly used for basic student record and performance
management.

It can be used to:

- Add student details and marks
- View student records
- Search for a student
- Update student information
- Delete a student record
- Calculate total marks and percentage
- Display grade and pass/fail status
- Check class statistics
- Find the top 3 performers
- Analyse marks subject-wise
- Save student records in a JSON file

The current version works through the command line.

## Target Users

This project can be useful for:

- Students
- Teachers
- Beginners learning Python
- Anyone who wants to manage basic student records

## High-Level Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Student Performance
- Class Statistics
- Top 3 Performers
- Subject-wise Analysis
- JSON data storage
- Input validation
