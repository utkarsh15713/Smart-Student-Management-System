# Smart Student Management System

## Project Overview

Smart Student Management System is a Python-based command-line project made to manage student records.

It can store student details and marks and also calculate total marks, percentage, grade, and pass/fail status. The project also provides some basic analysis of student performance.

Student data is stored in a JSON file so that the records can be used again when the program is run.

## Features

- Add a new student
- View all students
- Search for a student
- Update student details
- Delete a student
- Check student performance
- View class statistics
- Find top 3 performers
- View subject-wise analysis
- Calculate total and percentage
- Calculate grade and pass/fail status
- Store data in JSON format
